# Derived data

`derived/attempts_screened30.csv` retains all attempts in the screened pool,
including missing numeric outputs. No photographs, depth arrays, masks, locations,
names, original UUIDs, free-form inspection notes or private comments are included.
Capture numbers are study identifiers, not addresses. Front IDs and within-capture
pane references are pseudonymised; only the private companion retains the map.

Reference dimensions are author-confirmed Leica DISTO measurements. This is an
author clarification; raw capture instrument labels have not been overwritten.
The 27-capture cohort is fixed in `primary27`; its 48 intended pane references
are capture/reference pairs, not a count of independent physical windows.
The screened pool contains 30 captures and 52 such references.

The dataset is a derived observational record for descriptive reproduction.

trained weights, vendor code or the product app.
